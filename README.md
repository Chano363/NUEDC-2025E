# 自动寻迹瞄准装置 · 2025 全国大学生电子设计竞赛 E 题

小车在 100cm×100cm 的方形轨迹上按设定圈数自主行驶，同时由视觉模块识别靶面光斑坐标，驱动二维云台完成静态瞄准与行驶中的动态追踪。本仓库为 2025 年参赛代码。

## 技术栈

- **循迹主控**：TI MSPM0G3507，C 语言，灰度传感器循迹、编码器测速、速度 PID 闭环
- **云台主控**：STM32G474，步进电机驱动、二维云台控制
- **视觉**：K230 CanMV / MicroPython，矩形靶面检测与光斑识别
- **惯导**：ICM42688 六轴陀螺仪，UART 数据解算
- **通信与调试**：UART、I2C、蓝牙在线调参、OLED 状态显示

## 系统方案

系统由循迹小车与二维云台两部分组成。MSPM0G3507 负责小车循迹、测速与运动控制，STM32G474 负责云台的步进电机驱动与姿态解算，K230 视觉模块独立完成靶面与光斑检测并通过串口下发坐标。三轮之间通过 UART 交换位置与姿态信息，实现"循迹—识别—瞄准"的联动。

循迹方案在开发过程中由开环改为"中心旋转 + 闭环"控制，配合编码器测速构成速度闭环，使小车在转弯与启停段的轨迹稳定性明显提升。

## 我负责的部分

搭建 MSPM0 循迹小车的灰度循迹、编码器测速、速度 PID 与蓝牙命令解析程序，实现方形轨迹 1~5 圈可设定行驶；完成 ICM42688 陀螺仪的数据解算与三轮联调，主导把循迹方案从开环升级为"中心旋转 + 闭环"；实现 K230 端矩形靶面与光斑检测、串口坐标下发，配合 STM32G474 云台完成二维瞄准控制；绘制主控底板并完成硬件装配。

## 关键实现

**中心旋转 + 闭环循迹。** 相比传统差速转向，中心旋转让车体在原地完成大角度调整，减少转弯半径带来的轨迹偏差；编码器测速结果回灌速度 PID，形成闭环调节，抑制负载变化引起的速度波动。

**陀螺仪数据解算。** ICM42688 通过 UART 输出原始数据，主控完成解析后用于姿态补偿，配合视觉坐标一起驱动云台瞄准，提升动态追踪时的指向稳定性。

**视觉坐标下发。** K230 检测矩形靶面四角与光斑中心，计算光斑相对靶心的像素偏移，按固定帧格式经串口下发 STM32G474，云台据此驱动步进电机完成瞄准。

## 调试记录

- **循迹不稳**：开环方案在转弯段累积误差明显，改为中心旋转 + 编码器闭环后轨迹收敛。
- **陀螺仪联调**：多模块同时占用 UART 时出现数据错位，通过统一帧格式与波特率配置解决。
- **三轮联调**：小车、云台、视觉分别调试通过后，再逐级接入联调，避免故障定位困难。
